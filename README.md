# VMT Creative Studio

Build a premium, modern, highly interactive one-page website for a Hungarian creative marketing agency called VMT – Visual Media Team.

IMPORTANT:

* The visible website language must be Hungarian.
* Use the uploaded VMT logo as the primary logo. Do not create a new logo.
* The brand name should primarily appear as VMT, with “Visual Media Team” used only where appropriate.
* Do NOT make the website look like a generic marketing agency template.
* The website should feel like a premium creative studio: minimal, confident, modern, visual, professional and conversion-focused.
* Use our own photos/videos as much as possible.
* Avoid excessive gradients, cheesy marketing graphics, stock-photo aesthetics and generic agency clichés.
* The website must be fully responsive, especially optimized for mobile.
* Make the website feel alive and interactive while scrolling.

BRAND / VISUAL DIRECTION

Create a sophisticated visual identity around the existing VMT logo.

Design direction:

* Minimalist
* Premium
* Editorial / creative studio aesthetic
* Strong typography
* Large visual elements
* Generous whitespace
* Subtle motion
* Smooth scrolling
* Micro-interactions
* High-quality video presentation
* Strong contrast
* Elegant transitions
* Modern grid system

Use a mostly neutral color palette based on the uploaded logo, with one subtle accent color derived from the logo.

Typography:

* Use a modern, premium sans-serif font.
* Very strong large headlines.
* Clean readable body text.
* Use different font weights to create hierarchy.

Animations:

* Smooth scroll-triggered animations.
* Elements should subtly fade, slide, scale or reveal as the user scrolls.
* Do not over-animate.
* Animations should feel expensive and intentional.
* Add subtle hover interactions to buttons, cards, videos and portfolio items.

The page should feel like it is progressively being “built” as the user scrolls through it.
